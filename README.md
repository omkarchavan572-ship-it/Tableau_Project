⚡ EV Charge & Range Analytics

A data visualization project that analyzes Electric Vehicle (EV) charging patterns, battery range, and adoption trends using SQL, Tableau, and a responsive web interface.

This project presents insights through interactive Tableau dashboards embedded in a modern web interface built with HTML and TailwindCSS.

📌 Project Overview

The goal of this project is to analyze electric vehicle data and visualize insights related to:

EV battery range

Charging infrastructure

Vehicle types

Model year trends

EV adoption patterns

The analytics are displayed through interactive dashboards and story visualizations to make the data easier to explore and understand.

🚀 Features

📊 Interactive Tableau Dashboard

📈 EV Story Visualization

📱 Responsive UI using TailwindCSS

🔍 Data analysis using SQL

🌐 Embedded analytics in a web page

📂 Project Workflow
1️⃣ Data Collection

EV datasets were collected from database sources including:

Vehicle type

Electric range

Model year

Charging infrastructure

2️⃣ Data Preparation

The raw dataset was cleaned and transformed using SQL queries to prepare it for analysis.

Tasks included:

Removing missing values

Data transformation

Filtering relevant attributes

Structuring data for visualization

3️⃣ Data Visualization

Interactive dashboards were created using Tableau Public to analyze:

EV adoption trends

Battery range comparison

Charging infrastructure analysis

Model year distribution
